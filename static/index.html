PREDICTION MARKET RESEARCH

Find the price of a logical contradiction.

For a shared outcome, “above 85” implies “above 80.” This lab checks whether a threshold ladder can be bought for less than its minimum payout, using displayed order-book depth and a configurable fee model.

THE PAYOFF IDENTITY

YES(X > a) + NO(X > b) ≥ 1

For a < b, one side always pays. Between the thresholds, both pay.

A trade is flagged only if modeled cost + fees < $1 per matched pair.
